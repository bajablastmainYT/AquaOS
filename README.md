# AquaOS

AquaOS is a Vibe Coded small desktop-style experience built as a single HTML page. Open it in a web browser to explore a custom desktop, app launcher, and built-in apps.

## Features

- **First-run setup and lock screen:** Set a display name and a four-digit PIN. AquaOS opens to the lock screen on later visits.
- **Launchpad:** Open a searchable grid of apps from the dock.
- **Aqua Browser:** Enter a website address or search phrase. Some sites block being shown inside AquaOS; use the open-in-new-tab button for those.
- **Notes:** Write notes that save in your browser on this device.
- **To-do:** Add tasks, mark them complete, and remove them. Tasks save in your browser on this device.
- **Calculator:** Do basic arithmetic.
- **Calendar:** Browse months and save notes on dates in your browser.
- **Clock:** Use a stopwatch or countdown timer.
- **Aqua Paint:** Draw with a choice of colors and brush sizes, then save your drawing as a PNG.
- **Music:** Choose an audio file from your device and play it in AquaOS.
- **Settings:** Change your display name and PIN, or choose an Ocean, Midnight, or Sunset wallpaper.
- **Control Center:** Click **Wi-Fi** in the top bar to open brightness and volume controls. Brightness adjusts the AquaOS page. Windows manages your actual Wi-Fi and system volume.

## Run AquaOS

1. Download The AquaOS.html and Click on the File to open it in your browser.

AquaOS can also be hosted as a static webpage, such as with GitHub Pages.

## Data and limitations

AquaOS is a browser project, not a bootable operating system. It does not replace Windows or control the computer’s hardware.

The setup PIN is a visual lock for this demo only. It is stored in the browser and does not protect your Windows account or files. Notes, tasks, calendar entries, and settings are saved locally in the browser on that device. Music files are selected from your device for playback; AquaOS does not upload them.

Aqua Browser uses an embedded webpage. Some websites prevent embedding for security reasons, so they may need to open in a regular browser tab instead.
